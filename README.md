# النطاق العربي 6 — Elite Mopar Website
موقع عربي RTL متجاوب لمركز متخصص في سيارات موبار.

## بيانات المركز
- واتساب: +966 53 292 1615
- الموقع: صناعية العاصمة – مخرج 28 – الرياض
- العلامات: Dodge, Chrysler, Jeep, RAM, SRT

## النشر
1. فك ضغط الحزمة.
2. ارفع `index.html` و`styles.css` و`script.js` مباشرة إلى جذر مستودع GitHub.
3. افتح Settings > Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.

## ملاحظات
- الصور روابط خارجية تجريبية من Unsplash وليست صوراً مؤكدة للمركز. استبدلها بصور حقيقية للورشة والسيارات بعد الحصول على الموافقات.
- الخريطة رسم توضيحي ورابط بحث نصي، وليست دبوساً جغرافياً مؤكداً.
- نموذج الحجز يفتح رسالة واتساب ولا يحفظ الطلبات في قاعدة بيانات.
